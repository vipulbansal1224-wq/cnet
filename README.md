## 🚀 How to Run Locally

### Prerequisites
- Node.js 18+ or 20+
- npm

### Commands
```bash
# Navigate to the project directory
cd C:\Users\adfmin\.gemini\antigravity\scratch\cnet-ludhiana-portal

# Start production server (already built)
npm run start

# Or run in development mode
npm run dev
```

Visit in your web browser:
**`http://localhost:3005`**
